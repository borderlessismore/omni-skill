# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-23

### Added
- `omni` skill: cross-source answers in Brief, Find, Timeline, Connect and Audit modes, with links, conflicts and gaps.
- `omni-onboarding` skill: guided setup of the Omni Config and Omni Index in Notion, Google Drive, a local folder or a Project, with first backfill, pinning and a test query.
- `omni-capture` skill: captures conversations, whole claude.ai Projects or single documents into the index, with deduplication and validation.
- Shared index schema and `omni_index.py` (init, validate, search with vocabulary expansion, add, stats), standard library only.
- Claude Code plugin and marketplace manifests.
- Examples, behaviour evals, unit tests, CI validation and release packaging.
